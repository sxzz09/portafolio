## <img src="https://cdn.simpleicons.org/git/EF4444" height="18"/> Local Development

To run this project locally:

```bash
# 1. Clone the repository
git clone [https://github.com/sxzz09/portafolio.git](https://github.com/sxzz09/portafolio.git)

# 2. Navigate to the project directory
cd portafolio

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev

Open http://localhost:3000 with your browser to see the result.
